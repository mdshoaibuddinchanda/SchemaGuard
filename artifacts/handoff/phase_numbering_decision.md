# Phase numbering decision

SchemaGuard uses two compatible labels for this work:

* Completed repository Phase 01: smoke-data foundation and grouped-split correction.
* Operational Phase 02A: model runtime compatibility gate.
* Master-plan correspondence: the environment-compatibility phase.
* Future Phase 02B: acquisition and validation of the remaining SchemaOrbit-14 datasets.

This naming decision changes no scientific configuration, frozen model, dataset,
view, metric, seed, split strategy, or checkpoint.
